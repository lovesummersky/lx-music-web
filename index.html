                  关于这个精简版

                  来源：lovesummersky/lx-music-desktop（上游 lyswhut/lx-music-desktop，v2.12.6，Electron + Vue 3）。桌面版原样跑不到 Worker 上：它依赖 Electron IPC、主进程 SQLite、隐藏窗口脚本沙箱和 Node 网络/文件能力。

                  这个精简版不是逐行移植：前端是新写的单页播放器；Worker 层复用了已实测的搜索适配器（QQ / 酷我 / 酷狗 / 咪咕按洛雪内置思路重写）与脚本代理（/proxy、/proxy-fetch、/proxy-source），播放地址解析复用洛雪脚本隔离 Worker 的做法。已补齐的桌面功能：榜单、发现、外部歌单导入、多歌单管理、播放历史、本地音乐（浏览器 IndexedDB）、主题切换、倍速、睡眠定时、全屏歌词、弹出歌词窗、浏览器下载、音源检测。

                  Worker 上确实做不了的：系统托盘、全局快捷键、开机自启、Scheme URL、本地 Open API 服务、服务端磁盘下载、跨设备数据同步（无服务端存储）、桌面歌词窗常驻置顶（可用弹出歌词窗代替）、本地文件夹自动扫描（只能手动选文件）。这些要走服务器部署（常驻 Node + 磁盘）才能做。

                  • 搜索：5 个平台；网易云搜索 / 歌词 / 封面仍走默认 GD 上游，GD 波动时会失败。
                  • 试听片段保护：解析出的地址先看元数据时长，不到歌曲全长七成判为片段，自动换下一个音源；全部是片段则跳下一首。元数据拿不到时长时无法判断。
                  • 跨平台代播：QQ 只有片段时，会试一次同名同歌手的酷我 / 网易云完整版，提示后播放，播放列表本身不改。
                  • 没有：数据同步、桌面歌词窗、托盘、快捷键、账号登录。本地歌曲与浏览器下载已补齐：下载走 Worker 流式中转（/download，仅放行音乐 CDN 域名），直接保存为“歌手 - 歌名”文件名，不落盘。
                  • 免费额度：Worker 免费档每请求 10ms CPU、每天 10 万次请求；重签名 / 大解析可能超时，属平台限制。
